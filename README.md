# CyBreach Arena – Frontend

## Overview

CyBreach Arena is the frontend interface for the CyBreach Arena project. The frontend is developed using React and Vite.

The main interface is implemented in the `CyBreachArena.jsx` file.

> **Note:** The `cyberarena.zip` file contains the complete frontend project structure required to run the application. If the ZIP file is unavailable or cannot be extracted, the individual frontend files provided in the repository can be used to set up the project manually.

---

## Technologies Used

- React
- JavaScript
- JSX
- Vite
- CSS

### React

React is a JavaScript library used for building user interfaces. JSX is used to write HTML-like markup directly within JavaScript.

### Vite

Vite is used as the frontend development and build tool. It provides:

- A local development server
- JSX and modern JavaScript processing
- Fast development and hot module replacement
- Production build support
